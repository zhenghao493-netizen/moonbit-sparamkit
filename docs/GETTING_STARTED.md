# SParamKit 试用与交付说明

适用于 `0.1.0-dev.5`。功能仍限定为一端口、二端口 Touchstone S 参数的导入、检查、曲线和导出；不是射频仿真或仪器校准软件。

## 不安装开发环境也能使用

完整运行包解压后，使用桌面浏览器打开 `index.html`。离线工作台的使用不需要 MoonBit、Node.js、Python、登录或联网。单独保存的 HTML 也可运行。不要只在压缩包预览器里打开页面。

打开后应显示二端口陷波合成样例的 **291 个频点**。点击“单端口 RC 负载”应改为 **161 个频点**；这些仅是演示数据，不是本项目采集的仪器测量。

选择、拖入 `.s1p` / `.s2p`，或粘贴文本并选择正确端口数。文件最多 2 MiB，须为 UTF-8，交互接口最多 20,000 个频点。选择 `.txt` 时须自行确认端口数。输入修改后必须重新解析；旧曲线及旧导出应立即失效。

## 一份可手算核对的小输入

选择单端口并粘贴：

```text
# Hz S RI R 50
1 .3 -.4
2 0 0
```

应看到 2 个频点、50 Ω 参考阻抗。第一个点的幅度为 0.5，dB 约为 -6.0206，相位约为 -53.1301°。第二个点的有限 dB 与相位未定义，JSON 中须为 `null`，不能冒充为 0。

导出 JSON 应保留全部频点。导出 CSV 应有一行表头、两行数据。界面分页和当前选中的 S 参数不应截断全量导出。

随后点击“错误诊断样例”：应显示错误位置，清空旧结果，并禁用导出。再选择正常样例应恢复。文件编辑后可以重新选择同一文件，不需要先选择其他文件。

## 运行包完整性检查（可选）

运行包内的 `manifest.json` 记录版本、构建提交和各文件的 SHA256。Python 3.10 及以上可执行：

```bash
python verify_download.py
```

从其他目录执行可使用完整脚本路径，或显式传入运行包目录。应返回 `status: passed` 和已核对的文件数。修改文件、缺失文件或出现未列入清单的额外文件会导致失败。因此请在单独的解压目录里核对，把分析结果保存到其他目录。

这只是校验包内文件是否一致，**不是数字签名，不能单独证明来源真实或软件没有缺陷**。单独重命名的 HTML 不应拿来校验原运行包的文件清单。

## 命令行与源码

文件 CLI 需要 Node.js 22；核心解析和计算仍来自 MoonBit 编译产物。

```bash
node cli.cjs samples/synthetic_notch.s2p --format json
node cli.cjs samples/synthetic_notch.s2p --format csv > result.csv
```

从源码重建需要 MoonBit 工具链、Node.js 22 和 Python 3.11 及以上。浏览器单文件和 CLI 均不依赖 Python 的 scikit-rf 作为运行时解析器。复现细节以仓库 README 和验证日志为准。

自动浏览器场景不等于独立用户试用。390px 视口不等于 Android/iOS 真机；Playwright 的 WebKit 也不是苹果品牌 Safari。真实设备上的表现仍需单独记录。
