# SParamKit 使用指南

本指南介绍如何打开离线工作台、导入 Touchstone 文件和导出分析结果。

## 打开工作台

在 [工具构建页面](https://github.com/zhenghao493-netizen/moonbit-sparamkit/actions/workflows/web.yml) 选择成功的运行记录，从 **Artifacts** 下载 `sparamkit-tool`，完整解压后用桌面浏览器打开 `index.html`。请先解压，不要在压缩包预览器里打开。

获取 Actions 附件可能需要登录 GitHub；下载后的工作台可以离线使用，不需要安装开发环境。附件保留 30 天，过期后可按 [README](../README.md) 从源码构建。

页面默认载入双端口陷波样例，共 291 个频点。点击“单端口 RC 负载”可以切换到 161 个频点的单端口样例。这两份合成电路数据可用于熟悉界面。

## 导入文件与查看曲线

通过文件选择器或拖放区域载入 `.s1p` / `.s2p`，也可以直接粘贴文件内容。标准后缀会自动选择端口数；使用 `.txt` 或粘贴文本时，请确认端口设置。

文件须使用 UTF-8 编码，大小不超过 2 MiB，最多包含 20,000 个频点。完整格式说明见 [COMPATIBILITY.md](COMPATIBILITY.md)。

解析完成后，顶部显示频点数、频率范围和参考阻抗。选择 S11 / S21 / S12 / S22 查看相应的幅度、相位曲线，频率轴可以在线性与对数之间切换。

对数轴不显示 0 Hz 点，但表格和导出会保留。相位按主值显示，跨越 ±180° 时曲线断开。图表不做插值或平滑。

编辑文本或更改端口数后，点击解析按钮更新结果。旧曲线和导出会先清空；需要恢复原文件时，重新选择同一文件即可。

## 试一份小样例

选择单端口并粘贴以下内容：

```text
# Hz S RI R 50
1 .3 -.4
2 0 0
```

解析后应显示 2 个频点、50 Ω 参考阻抗。第一个点的幅度为 0.5，分贝约为 −6.0206 dB，相位约为 −53.1301°。第二个点的幅度为零，分贝与相位留空，JSON 中对应值为 `null`。

点击 JSON 或 CSV 导出结果。JSON 包含全部频点；这份样例的 CSV 包含一行表头和两行数据。对于双端口文件，导出同样包含所有参数，不受界面当前选择和分页影响。

## 处理导入错误

检查失败时，状态栏会显示错误码、行列位置和原因。修改相应内容后重新解析即可。

| 错误码 | 检查内容 |
| --- | --- |
| `MissingOptions` | 数据前是否有 `#` 选项行 |
| `IncompleteRecord` | 某个频点是否缺少参数；端口数是否选择正确 |
| `FrequencyOrder` | 频率是否重复或未按递增顺序排列 |
| `UnsupportedMetadata` | 已识别的端口阻抗声明是否完整，并与文件头的 R 值一致 |

阻抗冲突时，请核对文件的导出设置，不要只修改文件头来跳过检查。SParamKit 保留原参考阻抗，不进行阻抗重归一化。

“错误诊断样例”可以演示报错与恢复流程：加载后查看诊断信息，再切回正常样例继续使用。

## 使用命令行

完整运行包附带文件 CLI，需要 Node.js 22。在解压目录中执行：

```bash
node cli.cjs samples/synthetic_notch.s2p --format json
node cli.cjs samples/synthetic_notch.s2p --format csv -o result.csv
node cli.cjs input.txt --ports 1 --format json
```

`-o` 将结果保存为 UTF-8 文件，不覆盖已有文件。成功时退出码为 `0`；数据检查失败为 `1`；文件或参数错误为 `2`。标准输入、输出选项及诊断通道见 [命令行指南](CLI.md)。

## 检查运行包

运行包中的 `manifest.json` 记录版本、构建提交和文件哈希。需要核对下载文件时，使用 Python 3.10+ 执行：

```bash
python verify_download.py
```

检查通过会返回 `status: passed`。文件缺失、内容变化或目录中出现额外文件都会导致检查失败，因此请在刚解压的目录中运行，把导出的分析结果保存到其他目录。单独保存或重命名的 HTML 不使用这份原始包清单检查。

此功能检查文件一致性，清单本身不是数字签名。
