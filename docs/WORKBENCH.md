# 曲线读数与错误定位

## 读取某个频点

解析完成后，曲线上方的“频点读数”显示当前频率、实部、虚部、幅度、分贝和相位。移动鼠标到曲线上，可以读取距离指针最近的原始采样点；点击曲线还会将数据表翻到该点所在页。

也可以拖动滑块选择频点。滑块获得焦点后，左右方向键逐点移动，Home / End 跳到首尾。切换 S11、S21、S12 或 S22 时保留当前频点，便于比较同一频率下的不同参数。

读数来自 MoonBit 的计算结果，不进行插值。频率显示原始 Hz 数值，其他读数最多显示九位有效数字；鼠标停留在数值上可查看完整精度。分贝或相位未定义时显示“—”。

对数轴不显示 0 Hz，滑块仍可选中该点，表格和导出也会保留它。

## 跳到错误字段

输入未通过检查时，状态栏显示错误码及行列位置。点击“定位错误”，文本框会选中对应字段，便于直接修改。修改后点击“解析并查看曲线”重新计算。

定位操作本身不会修改文本。更换文件或编辑输入后，旧的读数、曲线和错误位置会清除。

## 较大的文件

工作台最多读取 20,000 个频点。滑块和表格翻页只更新读数及可见行，不会每次重建整条曲线。CSV 和 JSON 导出始终包含全部频点、全部 S 参数，与当前页和选中频点无关。

文件大小、编码及格式要求见 [格式支持说明](COMPATIBILITY.md)。完整使用流程见 [使用指南](GETTING_STARTED.md)。
