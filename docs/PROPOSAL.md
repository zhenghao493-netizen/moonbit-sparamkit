## 项目简介

本项目针对 MoonBit 社区任务 #142 提出的官方解析器测试与修复需求，维护 `moonbitlang/parser` 的语法一致性。该库提供 MoonBit 源代码的词法分析、语法树和解析能力。项目直接围绕已有社区任务，补充可复现的差分用例，定位有效 MoonBit 语法在手写解析器、生成解析器与工具链参考实现之间的差异，并为确认的问题提供修复和回归测试。

工作以锁定的上游提交 `a01fd77e599c12cf9a2182df3456990e74f53ced` 为基线。已有上游实现和测试仅作基础，不计作本期新增成果；本期按新增语法样例、最小复现、诊断记录、测试补丁及修复 PR 分别交付。

## 核心功能范围

以下为拟申报的本期工作范围：

- 固定上游源码和工具链版本，执行原有检查与测试，保留基线日志。
- 复用上游 AST 对照机制，为表达式优先级、模式匹配、带标签及可选参数、文档注释等语法组合补充回归样例；只将参考实现确认有效且未使用弃用语法的样例纳入兼容性判断。
- 分别执行手写 LL(k) 解析器、MoonYacc 生成解析器与 `mooninfo` 参考导出，记录结构化差异、诊断和失败输入。
- 将差异缩减为便于维护者审阅的最小复现；先区分版本差异、测试预期问题和解析器缺陷，再对确认的问题修复。修复逻辑和回归用例主要使用 MoonBit，Python 只承担进程调度和报告整理。
- 按上游贡献指南提供小范围测试或修复 PR，并在保持参考预期不变的情况下执行回归。没有发现差异的输入如实记录，不以更新全部快照消除失败。
- 提供本期新增工作清单、复现命令及修复前后结果，使评审能区分原有功能、本期贡献和待审补丁。

当前处于改题后的基线与小规模验证阶段；新增差分试验、修复以及上游 PR 的实际完成情况随开发记录更新。不会以复制上游代码或单纯重跑原测试作为本期完成成果。
