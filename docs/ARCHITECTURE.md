# SParamKit 架构与设计

SParamKit 将文件处理和射频数值计算放在 MoonBit 核心库中，浏览器与命令行复用同一份编译产物。项目围绕一端口、二端口 Touchstone 数据展开，主要流程是导入、检查、读数和导出。

## 模块分工

| 模块 | 职责 |
| --- | --- |
| `types.mbt` | 复数、频点、网络和诊断类型，以及参数查询与幅相计算 |
| `lexer.mbt`、`options.mbt` | 按行切分字段，检查十进制数值与选项 |
| `parser.mbt`、`metadata.mbt` | 组合频点记录，检查频率顺序和已识别的阻抗声明 |
| `export.mbt`、`report.mbt` | CSV 长表、JSON 报告和交互接口的输入限制 |
| `bridge/` | 暴露浏览器与 Node.js 使用的调用入口 |
| `web/` | 文件选择、文本编辑、工作线程、曲线和逐点读数 |
| `tools/` | CLI、构建、数值对照和验收包生成 |

公开接口见 [API 定义](../pkg.generated.mbti)，独立模块接入方式见 [库接入指南](LIBRARY.md)。

## 从文件到结果

浏览器读取本地文件后，先检查大小和 UTF-8 编码，再把文本与端口数传给工作线程。工作线程调用 MoonBit 解析入口；成功时得到按频率排列的 `Network`，失败时得到含错误码、行号、列号和原因的 `Diagnostic`。

解析器统一 Hz / kHz / MHz / GHz 单位，并将 RI、MA、DB 数值表示转换为实部和虚部。二端口数据保留 Touchstone 的 S11、S21、S12、S22 顺序；`get_s(0, 2, 1)` 查询第一个频点的 S21。

JSON 报告供界面显示，CSV 导出保留全部频点和参数。表格分页、当前参数选择和图上游标不改变原始数据，也不缩减导出范围。

## 关键设计

### 保留原始参考阻抗

文件头的 R 值直接保留。单位与数值表示的转换不会把数据重归一化到 50 Ω。对识别到的 `Port Impedance` 声明检查一致性，冲突时返回诊断，要求使用者核对原始导出设置。

### 将错误指向输入位置

词法处理为字段记录行列位置；后续选项、数值与记录检查沿用这些位置。工作台的“定位错误”按钮据此选中输入字段。错误输入不继续显示或导出上一份数据。

### 让界面状态与当前输入对应

每次输入变动会推进一个状态编号。解析和 CSV 请求完成时，只有仍属于当前输入的响应可以更新界面或触发下载。工作线程异常时清理待处理请求，下次操作再创建线程，输入文本保持不变。

### 避免常见浮点边界问题

幅度使用 `hypot`，分贝使用缩放分量和对数计算。这样在极小数或线性幅度溢出的情况下，仍可保留可表示的分贝读数。零复数没有有限分贝和确定相位，对应 API 返回 `None`，JSON 使用 `null`。具体公式和边界测试见 [数值说明](NUMERICS.md)。

### 为离线交付保留清晰边界

运行包只有单页工作台、CLI、样例和必要清单；不会调用在线模型或上传测量文件。验收包另外包含源码与本次报告，评审从根目录 `index.html` 即可进入演示。完整验收脚本检查结果后才组装交付文件。

## 如何验证

核心用例覆盖正常输入、错误位置、端口顺序与数值边界。独立模块测试检查公开 API 的接入；文档测试直接提取 README 和接入指南中的代码编译运行。数值测试分别使用高精度 Decimal 和 scikit-rf 对照，浏览器测试检查导入、读数、导出及异常恢复。

源包测试在新目录中重新构建，再次打包后比较文件内容。复现命令见 [演示与验收指南](ACCEPTANCE.md)，格式约定见 [兼容性说明](COMPATIBILITY.md)。
